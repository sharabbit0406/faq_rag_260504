客服 Widget 測試

在 iframe 中嵌入的即時對話機器人

📝 使用說明

  1. 將上方 iframe 中的 YOUR_TENANT_ID 替換成你的實際商家 ID
  2. 在輸入框輸入問題，按 Enter 或點擊「送」按鈕
  3. Widget 會根據你上傳的知識庫回答
  4. 若無法回答，會顯示「聯繫人工客服」按鈕

🔧 複製此程式碼到你的網站

<iframe src="http://localhost:3000/widget/YOUR_TENANT_ID" width="380" height="600" frameborder="0" style="border-radius: 10px;"> </iframe>

💡 客製化選項

在設定頁面可配置：

  • 商家名稱（顯示在 Widget 標題）
  • 聯絡 Email（無法回答時的轉接連結）
  • 拒答訊息（知識庫無相關資訊時的回應）
  • 歡迎訊息（用戶首次開啟時的問候）
